## Experimental branch

The `experimental/0.6.1` branch contains the community testing build, codename **Sizing Sneasel**, and its extended tooling. See [EXPERIMENTAL.md](EXPERIMENTAL.md) for feature and safety notes and the [Dragonwilds Sync modder documentation](https://gh0sted5456-us.github.io/Dragonwilds-Sync-Web/for-modders.html?build=b4a5199#runeschema-flavors) for installation, flavor, and compatibility guidance. Compiled test builds are distributed through this fork's Releases page rather than committed to the repository.
