## Experimental branch

The historically named `experimental/0.6.1` branch contains the current `0.6.2 Experimental` community testing build and its extended tooling. See [EXPERIMENTAL.md](EXPERIMENTAL.md) for feature and safety notes and the [Dragonwilds Sync modder documentation](https://gh0sted5456-us.github.io/Dragonwilds-Sync-Web/for-modders.html#runeschema-flavors) for installation, flavor, and compatibility guidance. Compiled test builds are distributed through this fork's Releases page rather than committed to the repository.
