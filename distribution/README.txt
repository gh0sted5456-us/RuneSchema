RuneSchema 0.6.1E

Copy the RuneSchema folder into the UE4SS Mods folder. Keep enabled.txt beside
the dlls, config, and mods folders. Place authored mod folders inside
RuneSchema/mods and control their enabled state and deterministic order with
RuneSchema/mods/mods.txt.

The included config is a clean recommended baseline. Drop scaling and developer
features remain opt-in. See config/README.md for every setting.
