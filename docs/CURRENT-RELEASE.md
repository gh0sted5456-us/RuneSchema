The **0.8.1.0** download is the complete maintainer-supplied package, published
unchanged. It is a testing candidate; it has not replaced stable 0.8.0.3.
GitHub's **Source code** archives are for development.

## What changed

Stable **0.8.0.3**, published October 28, includes selected-save cleanup,
nested Lua discovery for Mod Menu, item-family improvements, FPS controls and
registry refinements. Read the [stable changelog](CHANGELOG-0.8.0.3.md).

New Helpy, cache, controller, server and HUD changes are listed on the
[pre-release page](experimental/PRE-RELEASE.md#pending-changelog). Those changes
remain there until stable promotion; the normal guides describe stable behavior.

Close the game and choose **Exit Helpy** before replacing files. Preserve your
settings, mods, AppData profiles/caches and important saves. See
[installation](INSTALLATION.md) and [save safety](SAFE-SAVE-AND-LEDGER.md).
