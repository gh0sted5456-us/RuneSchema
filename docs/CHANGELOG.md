# RuneSchema 0.6.1E

Released by Jonesing4Space. RuneSchema 0.6.1E extends RuneSchema 0.6.0 by Snorkles, which is based on PalSchema by Okaetsu.

- Added consolidated logging for equipment and spawns, with detailed success output behind Advanced verbose logging.
- Added JSON/JSONC loader coverage, `$Patch`, clone authoring, cooked-pack discovery, and deterministic `AA_`/`ZZ_` ordering.
- Added asset-authored visual effects and examples for equipment, weapons, armor, characters, spawns, Blueprints, and resource nodes.
- Added validated Surge evade and Shadowveil stealth runtime behavior for matching client and server executables.
- Added bounded manual inspection, export, trace, and preset tools, plus organized Settings and Tools tabs.
- Retained explicit shipping size optimization, full-build evidence, symbols, maps, and UE4SS import validation.
