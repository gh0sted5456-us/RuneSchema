# Player Activity Nameplates

This test mod keeps the normal player name, then briefly displays a cooked game
icon when an attack, ranged attack, spell, woodcutting swing, or mining swing is
reported by the game's native multiplayer hooks. Death uses the verified fatal
damage state. No player action fields are polled.

Install the entire `PlayerActivityNameplates` folder under RuneSchema's `mods`
folder on the host and each participating client, then restart the game.
