# Player Activity Nameplates

This test mod normally hides the player nameplate, then displays a cooked game
icon for five seconds when an attack, ranged attack, spell, woodcutting swing,
or mining swing is reported by the game's native multiplayer hooks. Death uses
the verified fatal damage state. No player action fields are polled.

Install the entire `PlayerActivityNameplates` folder under RuneSchema's `mods`
folder on the host and each participating client, then restart the game.
