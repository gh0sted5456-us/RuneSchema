# RuneSchema source

This directory contains the buildable RuneSchema runtime, plugins, packaged
settings, UE4SS bootstrap, and Unreal authoring module.

Public authoring guides, loader references, schemas, and downloadable examples
live in [`../docs`](../docs) and are published on the
[RuneSchema documentation website](https://gh0sted5456-us.github.io/RuneSchema/).

Build RuneSchema with [`../Build RuneSchema.bat`](../Build%20RuneSchema.bat).
Generated packages are written to `../dist` and are not source-controlled.
