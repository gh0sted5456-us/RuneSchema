# RuneSchema 0.7.5.25

This release preserves the verified 0.7.5.24 WinGDK journal and mesh fixes,
independently validates Steam equipment behavior, and separates Steam loose
save handling from Xbox WGS provider storage.

- `RuneSchema-0.7.5.25-Universal.zip` includes the optional Helpy plug-in.
- `RuneSchema-0.7.5.25-Core.zip` contains the plugin-free core.
- Both RuneSchema packages include `enabled.txt`, mappings, and an empty
  `RuneSchema/mods` directory.
- Use the UE4SS archive matching the storefront installation.
