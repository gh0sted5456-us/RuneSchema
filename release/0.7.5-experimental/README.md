# RuneSchema 0.7.5 Experimental

These are ready-to-install, drag-and-drop runtime packages built from the
verified RuneSchema 0.7.0 clean source baseline.

- [Steam/GOG runtime](RuneSchema-0.7.5-Steam-GOG.zip)
- [Game Pass/WinGDK runtime](RuneSchema-0.7.5-GamePass-WinGDK.zip)

Matching UE4SS builds are included separately:

- [UE4SS for Steam/GOG](UE4SS-3.0.1-f6d5f942-Steam-GOG.zip)
- [UE4SS for Game Pass/WinGDK](UE4SS-3.0.1-f6d5f942-GamePass-WinGDK.zip)

The storefront-specific behavior is isolated in RuneSchema's core DLL.
RuneSchema.Helpy is the same API-client DLL in both packages.
