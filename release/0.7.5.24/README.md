# RuneSchema 0.7.5.24

This test release corrects the Game Pass/WinGDK journal hierarchy insertion
binding while preserving the 0.7.5.23 wearable-mesh and character-mapping
changes. Steam/GOG uses its unchanged native lane.

- `RuneSchema-0.7.5.24-Universal.zip` includes the optional Helpy plug-in.
- `RuneSchema-0.7.5.24-Core.zip` contains the plugin-free core.
- Both RuneSchema packages include `enabled.txt`, mappings, and an empty
  `RuneSchema/mods` directory.
- Use the UE4SS archive matching the storefront installation.
