# RuneSchema 0.6.1E

This GitHub release package contains the RuneSchema runtime, its matching source and symbols, the required UE4SS StackFix1 runtime and source, and the full 0.6.1E release notes.

Normal equipment output is one Shadowveil/Surge summary. Normal spawn output reports new, altered, errors, AI with boss count, resource nodes, other actors, and removals. Native binding totals and successful per-entry details require Advanced verbose logging. Warnings and errors remain visible.

`UE4SS - RuneSchema.zip` is the required StackFix1 host package. Its `version.dll` is the dedicated-server entry point; single-player clients ignore it.

Install only while the game and dedicated server are stopped. RuneSchema 0.6.1E remains dependent on the supplied UE4SS StackFix1 host.
