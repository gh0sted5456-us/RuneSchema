# RuneSchema 0.7.6.1

Use `RuneSchema-0.7.6.1-Universal.zip` for a complete drag-and-drop install. It contains the shared RuneSchema runtime and both storefront lanes; the DLL selects Steam/GOG or Game Pass/WinGDK at runtime.

Use `RuneSchema-0.7.6.1-Core.zip` only when the matching UE4SS runtime is already installed.

This release fixes authoritative recipe-to-journal resolution, reinforces authored journal identities after reflection, and expands native player/nameplate controls without adding storefront-specific signatures.
