# RuneSchema 0.7.5.23

Clean release artifacts for the unified Steam/GOG and Game Pass/WinGDK build.

- `RuneSchema-0.7.5.23-Universal.zip` includes the optional Helpy plug-in.
- `RuneSchema-0.7.5.23-Core.zip` contains the plugin-free core.
- Both packages include `enabled.txt` and an empty `mods` directory.
- Both packages use the same dual-lane `main.dll`.
- The matching Steam/GOG and Game Pass/WinGDK UE4SS runtimes are included as
  separate downloads.
